# Next.js Frontend

## Steps

### 1. Go into the Next.js folder

```bash
cd next-frontend
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run the frontend

```bash
npm run dev
```

### 4. Open in browser

```text
http://localhost:3000
```

---

## After pulling new changes

```bash
git pull
```

Then:

```bash
cd next-frontend
npm install
npm run dev
```
