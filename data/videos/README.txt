IBVAP Test Video Directory
===========================

Place your test video file here named:

    test_cctv.mp4

The application will not start the video feed until this file exists.

Recommended sources:
- https://www.pexels.com/videos/  (free stock videos)
- https://pixabay.com/videos/     (free stock videos)
- Any .mp4 file you own

The video will loop continuously to simulate a running CCTV camera.
To change the filename, update CAMERAS in backend/config.py.
